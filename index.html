Bug bounty

Finding bugs before attackers do.

I test web apps for common vulnerabilities and report them responsibly, only on in-scope targets and with permission.

What I look for

  • Cross-site scripting (XSS)
  • Broken access control and IDOR
  • Injection flaws
  • Authentication and session issues
  • Security misconfigurations

How I work

  • Recon and OSINT on in-scope assets
  • Manual testing of logic and inputs
  • Clear, reproducible reports
  • Impact and a suggested fix in every report

Rules I follow

  • In-scope targets only
  • No data theft, no damage
  • Responsible disclosure first
  • No public details until fixed

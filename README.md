# Satyam Gupta | Portfolio

Live site: https://invisiblehqck.github.io/
ONEWHO address: https://invisiblehqck.isonewho.codes/

My personal portfolio for One Who Codes 2026. It shows who I am (full-stack developer, cybersecurity and digital forensics intern, AI/ML student, founder of The AI GUY), what I build, and how to reach me.

## What is in it

- A 3D world drawn with Three.js: a crystal in the header, a cube with orbiting panels in the middle (drag to spin it), and a network globe in the footer. The camera travels between them as you scroll.
- A code-rain background that reacts to the cursor, a terminal-style intro line, and glowing card borders that follow the pointer.
- Sections: About, Services, Projects, Bug bounty, Experience, Community, Swag, Contact.
- Light and dark theme, a music toggle (a soft loop generated in the browser, off by default) and an Effects toggle that turns off the 3D and animations.

## Built with

HTML, CSS and vanilla JavaScript in a single page. Three.js (loaded from a CDN only when effects start). Web Audio API for the music. No framework and no build step.

## Performance and accessibility

- Effects start after the first interaction, so the page shows content first.
- Code rain is off on small screens. Reduced-motion users get no animation.
- Skip link, labelled controls, keyboard focus styles, and alt text on images.

## How it was made

I designed the structure, wrote the content, and supplied all projects, photos, screenshots and video. I used an AI assistant (Claude) to help write and refine the code, and I edited, tested and deployed it myself. All text, projects, images and links are mine.

## Run it locally

Open `index.html` in a browser. There is nothing to install.
